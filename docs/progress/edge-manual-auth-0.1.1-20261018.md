# Edge 手动认证 0.1.1

本次范围为扩展连接诊断和状态修复，不代表已修复 Edge 的 native_not_found。

- 保留原 manifest key、扩展 ID、权限和现有配对，不增加后台采集。
- 新增显式 ping：返回助手名称、协议和版本，不读取运行配置、任务或 Cookie；入口仍校验扩展 origin。
- 扩展显示版本和 ID，新增“检查本机连接”。检查成功只表示助手链路可用，不表示采集已恢复。
- 修复重新领取失败仍保留旧任务提交入口，以及初始化读取覆盖新领取任务的竞态。
- native_not_found 文案改为“未找到或未能加载”，不再断言注册项一定缺失。

验证：扩展 Node 测试 7 项通过，相关 Python 测试 30 项通过，Ruff 检查和格式检查通过；有效代码行检查器 19 项自测与 ratchet 通过。安装后 7 个文件哈希一致，原生助手消息往返、错误 origin 拒绝与新 ping 均通过。直接启动助手的验证不能替代 Edge 发起的端到端连接测试。

仅更新本机扩展静态文件和按请求启动的 Python 助手；没有修改桌面 EXE、运行配置、注册表、权限或配对数据，没有重启浏览器、NAS 或 PC2。部署脚本补入新 native.mjs 文件。

人工验收：在 Edge 扩展管理页重新加载 Crow 手动认证，关闭旧扩展页面并重新打开，确认版本为 0.1.1，点击“检查本机连接”。建议重新加载而非先卸载：卸载可能清除 extension storage 中的 profileId，而本机助手仍保留原配对；不得为修复安装问题自动清空配对。
