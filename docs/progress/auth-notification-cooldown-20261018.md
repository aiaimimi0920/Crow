# 认证失败后的自动重试冷却修复

## 范围与原因

用户保留完整浏览器详情采集，不引入轻量 HTML 优先路径。本次只修复 NAS 认证协调的失败重试准入，不修改页面采集、会话传递或 Edge 助手。

原实现允许 `seed_challenge_stalled`、`detail_challenge_stalled`、`node_solver_retries_exhausted` 在失败后的信号等待时间到期后绕过配置冷却。当前 NAS 冷却为 1800 秒；300 秒信号阈值可能提前生成新 recovery ID，使已有的同轮提示去重失效。

修复删除失败快速重试例外。重复失败信号遵守持久化冷却，不延长冷却，不把失败改成成功。到期并发报告仍只创建一个恢复轮次。人工主动认证、首次等待、无采集端禁止自动认证、成功后有真实新进度的恢复规则均保留。
