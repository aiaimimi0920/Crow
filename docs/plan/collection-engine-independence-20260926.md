```text

```

AI 提取、字段整理、来源证据关联及入库属于采集引擎。认证、人机接管、浏览器执行、
多机任务协调、暂停恢复、配置与日志，只在支撑这条链路的范围内纳入。

不开发、不优化其内部实现，也不把它们的验收作为采集引擎的完成条件。

网页中的价格、地址、司法公告、权属和风险陈述仍可能是需要采集的事实。
不能按 `avm`、`analysis`、`prediction` 等历史名字直接删除字段、模型调用或文件。
逐一根据实际调用和输出用途判断；事实提取属于采集，估值推导属于后处理。

## 3. 目标边界与完成定义

采集引擎在同一仓库中形成独立的代码与运行边界，优先复用 `src/collection/`。
外围 HTTP、桌面、浏览器和 PC2 程序通过明确入口调用它。暂不新建微服务、消息总线、
独立仓库或多套部署系统，也不为目录整齐而移动所有文件。

```text
HTTP / 桌面 / 浏览器 / PC2 入口
               |
               v
采集运行组合：配置、任务生命周期、认证、来源适配器
               |
     链接发现 -> 详情抓取 -> AI 整理 -> 采集存储
                                          |
                                  已归档记录与证据引用
                                          |
                                可选的后处理读取方
```

必须满足：

1. 采集启动、状态查询、任务执行和落库无需导入或初始化估价、预测、校准与分析工具。
2. 禁止加载后处理模块时，四阶段完整流程仍能完成。此条件必须覆盖传递依赖，
   不能只做静态文本搜索或只验证一个空数据库服务对象。
3. 完成表示必要证据和整理记录已按约定存储；后处理就绪、估值成功与否不参与判定。
4. 后处理停止、抛错或不可用，不改变采集任务的状态和结果；后处理不参与采集提交事务。
   本期证明应用调用与生命周期隔离，不承诺共享数据库/主机在资源耗尽时绝无影响。
5. 来源 ID、证据引用、现有字段和历史数据可读性保持；任何必要持久化迁移单列方案，
   有备份、重试和回退依据，不做破坏性字段删除或数据库重建。
6. 采集必需凭据与配置显式可用；不要求提供 AVM 配置、估价模型或后处理运行目录。

旧兼容入口只有存在实际调用方时才保留，放在引擎外的适配层。记录调用方与退出条件；
不添加新的函数克隆、全局赋值广播或永久双实现。未采用后处理代码暂时保留，
与采集执行断开，不借本期扩大为后处理重构。

## 4. 开发工作包

按依赖顺序交付下面 5 个实现包和 1 个最终验收包。每包闭合一段可用流程，
可在包内连续修改关联文件；不以迁移几个函数或增加一个接口作为交付终点。
以下模块名是职责描述，不预先强制创建同名目录或抽象层。

### C1：采集记录、来源规则与存储归属

状态：记录构造、来源策略、存储写入与读回已实现并验证。对应旧 R1/R2 中影响独立性的部分。
见 [C1 存储检查点](collection-c1-storage-checkpoint-20260926.md)。原生 CollectionRepository
在禁止加载 AVM/tools 的两个新进程中完成来源 seed/detail 存取；既有 server 入口尚待 C2 切换。

- 沿真实入库调用梳理 `collection_template`、canonical record、stage state 的传递依赖，
  只把采集事实构造和验证放到采集/存储契约中。估值派生、分析 readiness 留在后处理侧。
- 由来源适配器提供采集必需字段、链接规则和完成规则；存储不自行构造 Taobao 语义。
  复用已有 adapter 和 search policy，避免建立另一套策略框架。
- 明确抓取成功、AI 整理成功、归档入库成功之间的区别。旧 `analysis_*` 字段可能表示
  AI 整理，逐项映射，不能全局重命名或一次删列。
- 保留来源身份、原始字段、证据路径和已有数据库 schema；将需要独立迁移的事项列明。

交付：普通采集记录可在禁止导入 AVM 模块时构造、保存和读回；种子与详情使用同一
身份契约；历史记录仍可读取。复用 generic/source policy、canonical 和 DB dual-write
测试，新增的回归只覆盖原测试没有证明的依赖隔离与记录保存行为。

[C2 启动检查点](collection-c2-startup-checkpoint-20260926.md)。对应旧 R1/R4/R6 的采集边界。

- 为采集建立明确的组合入口，配置采集根目录、repository、adapter、AI、runtime 和

- 把 server/context 中的后处理注册与实例创建移出采集必需启动路径；现有命令和

- 采集状态直接读取采集服务和任务指标，不再调用 AVM 健康或分析摘要。

操作失败。单纯 import 成功、mock 健康返回或空服务初始化不足以验收。

交付：真实隔离存储上的链接/HTML -> fake AI -> DB 记录和证据引用完整可读；归档或

6. 已通过且相关输入未变化的检查复用证据。记录提交与覆盖范围，明确历史结果不等于
   当前全量通过；不为了刷新数字重复执行套件。
7. 每个完整工作包保留一个可回溯提交和简洁记录。只有阻断本包完成的问题立即处理；
