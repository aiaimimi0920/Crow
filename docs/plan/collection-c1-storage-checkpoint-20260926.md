## 本包交付

- 采集记录 schema、冻结 JSON 契约、金额/面积解析、小区事实规范化移到采集目录。
  旧 AVM 导入位置为现有工具和兼容路由保留原函数的普通导出，没有全局广播或函数复制。
  没有优化估价算法或改变冻结字段。JSON 契约按 LF 规范化后的全文与迁移前相同，
  SHA-256 为 `d20de4a762ea49e23150295f50972e45077e5f196c68d88d95e0658de40b0b32`。
- `CollectionRepository(settings, adapter=...)` 提供采集存储入口，来源适配器显式供应
  记录构造、搜索和 seed policy。默认通用采集不再默用 Taobao 规则；未显式传入 policy
  时，通用来源的种子写入仍检查任务归属和 worker 租约。URL 来源识别移到采集策略层。
- 原 `PropertyRepository` 保留当前 server/工具需要的行为，包括旧分析状态投影和历史
  `_seed_item_url` 调用。两者共用同一批持久化实现，没有双写实现或数据复制。
  该兼容入口的调用方退出条件是 C2 完成启动与消费者迁移，不作为永久新架构。
- 原生采集状态计算只处理 seed/detail；旧分析投影在兼容路径显式调用。
  原生写入不计算估价 readiness，不写分析阶段事件，也不覆盖已有分析状态、模型版本
  和评分时间。采集入库完成不受这些字段影响。
- 保留现有数据库 schema、来源身份、未知扩展字段、证据引用和旧行的读回方式。
  重试不会把无 canonical envelope 的旧行隐式升级；显式回填仍是独立操作。
