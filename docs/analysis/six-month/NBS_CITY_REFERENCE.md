# 国家统计局城市趋势对照（不是小区成交真值）

独立只读 CLI，不接入模型 fit、调参、留出评分，也不改变采集。

```powershell
python -B -m src.analysis.six_month.city_reference https://www.stats.gov.cn/xxgk/sjfb/zxfb2020/202507/t20250715_1960403.html
```

只输出冻结训练城市北京、武汉、温州、宜昌的表 2 二手住宅环比指数（上月=100）。不会输出上海、金华等留出城数值；佛山、淮安不在该 70 城范围。缺完整表、非正/非有限指数、时间异常均拒绝。无外部依赖、无写入，无登录、无新增服务或付费。

已实际读取的官方档案：
- 2020-06：https://www.stats.gov.cn/sj/zxfb/202302/t20230203_1900778.html ，正文发布时间 2020/07/16 09:30。
- 2025-06：https://www.stats.gov.cn/xxgk/sjfb/zxfb2020/202507/t20250715_1960403.html ，PubDate 2025/07/15 09:30。
- 2026-10：https://www.stats.gov.cn/sj/zxfb/202611/t20261116_1965836.html ，PubDate 2026/11/16 09:30。

时间为北京时间；2020 页 URL 的 202302 是迁移路径，不能作为原发布日期。输出分别保存观察月、发布时间、下载时间与原 HTML SHA256。当前下载不能证明原发布 vintage 未修订，故 `historical_vintage_verified=false`、输入可得时点保守设为本次下载时点。`visible_asof` 拒绝将今天下载的快照回填过去预测。历史数据只作事后城市级趋势参考，不用其声称实时回测。

指标覆盖市辖区、不含县，二手住宅为重点及典型调查、经纪机构/平台与实地采价等，并非逐套网签真值。官方有无成交视为总体持平的约定，2026 有基期轮换；不能把该约定复制成 Crow 缺失单价填零或持平。环比不得当同比或每平方米价格。未核齐连续六个月时不计算六个月累计收益，不能把本次三个抽查月直接连乘。

本片仅让合法公开官方数据可运行地读取、校验和限定用途，不产生预测、不解除真实小区标签缺口。网站公开统计数据用于附来源的研究对照；不复制站点全文或宣称其具 CC 授权。

修订验收：表头必须明确为双栏城市/环比/同比及上月/上年同月基准顺序，换列或未知布局拒绝；观察月份用日历验证，拒绝 0 月/13 月。最后响应也核验 HTTPS。台式恢复后已应用这三项修订，独立复核另行记录。
